I used a joystick to control my visual novel, in Arduino IDE is a script that sent raw serial numbers from the joystick positions to the computor.
I then followed a tutorial for a subway surfers controller because it also uses the same Arduino joystick and subway surfers operates on WASD.
<img width="973" height="1135" alt="image" src="https://github.com/user-attachments/assets/a39d6af0-1f89-4516-bd7a-2f5fbfebb3a2" />
Now when my joystick goes in a direction, it would send WASD. I went to my visual novel's code in renpy and added a script to the game folder.
<img width="1432" height="928" alt="image" src="https://github.com/user-attachments/assets/8c37252e-3d76-4a63-84e3-21e178287c4f" />
This allows for the visual novel to use the WASD input to select different objects. WASD moved the selector different directions and space would have the object the selector was hovering over be selected.
